# 3D 모델링 작업 지침

- 이 폴더에서 모델링하고 제작 노하우를 축적한다. 먼저 `README.md`, 관련 `knowledge/` 문서와 캐릭터의 `WORKLOG.md`를 확인한다.
- 캐릭터별로 `references/`, `source/`, `scripts/`, `output/`, `previews/`를 사용한다. 원본을 보존하고 수정본은 `output/`에 저장한다.
- 공식 자료의 설명, 직접 실행한 작업, 렌더로 확인한 결과와 아직 검증하지 않은 사항을 구분한다. Tripo 흐름을 참고한 Blender 작업을 Tripo 생성 결과라고 쓰지 않는다.
- 정면뿐 아니라 측면·후면·얼굴을 확인한다. 특히 머리와 목걸이가 몸에서 떠 있는지, 천과 피부가 관통하는지 검사한다.
- 모델을 수정할 때 재현 스크립트와 `WORKLOG.md`를 함께 갱신한다. 재사용할 수 있는 실패 원인과 해결책은 `knowledge/`에 추가한다.
- 기존 리그를 사용하는 작업은 본 이름·계층·rest matrix와 가중치를 검사한다. 정지 렌더만 통과한 모델을 애니메이션 또는 모바일용으로 검증됐다고 하지 않는다.
- 사용자가 Blender에서 보여달라고 요청하면 결과 `.blend`를 실제로 열고 모델과 미리보기 경로를 알려준다.
