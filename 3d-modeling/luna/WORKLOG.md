# 루나 작업 기록

## 2026-10-19 — 콘셉트 시트에 따른 개선

입력: `references/luna_concept.png`. 시작 모델: `source/luna_base.blend` (기존 `assets/celestial-oracle/luna.blend` 사본). 텍스처도 `source/textures/`에 복사해 보존했다.

기존 정면·얼굴 렌더에서 긴 헤어 카드의 각진 윤곽과 투명 겹침, 과도한 머리 반사, 양쪽 남색 리본의 부재, 금색 위주 초커를 확인했다. 원본 디자인의 갈색 웨이브 헤어·남색 리본·남색 초커·금색 테두리를 우선 반영한다.

제작: `scripts/refine_luna.py`. 기준 모델에서 다시 시작하는 방식으로 반복 실행하며 최종 결과는 `output/`에 저장한다.

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --python 3d-modeling/luna/scripts/refine_luna.py
```

Blender 5.1.2가 샌드박스 안에서 시작 시 종료되는 것을 확인했다. 승인된 Blender 실행 권한으로 작업한다.

### 수정 내용

- 긴 투명 헤어 카드를 입체 갈색 웨이브로 교체. 양쪽 묶음과 등 중앙 머리를 분리해 반묶음 실루엣으로 구성.
- 남색 양쪽 리본과 긴 리본 꼬리, 금색 테두리, 작은 별 장식 추가.
- 남색 초커, 중앙 원형 보석, 별 귀걸이와 다이아몬드 목걸이 구성.
- 피부에서 떠 있던 목걸이 체인은 몸·얼굴 BVH에 투영. 어깨에 뜬 기존 칼라 제거.
- 소매·치마에 부드러운 곡면을 적용하고 소매 금색 테두리·상체 봉제선을 추가.
- 5개 카메라, 부위별 컬렉션, 파일 안에 패킹한 원본 참고 이미지와 텍스처 제공.

### 반복 작업에서 확인한 문제

첫 렌더: 새 머리가 앞머리보다 밝고 굵었다. 색 공간과 반사를 고려해 재질을 조정하고 앞쪽 가닥을 줄였다.

측면 렌더: 정면에서는 보이지 않던 머리·목걸이의 부유를 발견했다. 높이별 헤어 경로와 실제 피부 투영으로 수정했다.

후면 렌더: 양쪽 머리만 있어 원화의 반묶음 실루엣과 달랐다. 중앙 커튼 형태의 긴 머리를 추가했다.

### 저장·구조 검증

`output/luna_refined.blend`에 저장. `output/validation.json`에서 원본 176개 본의 이름·부모·rest matrix 보존, 가중치 합, 본 참조, 유한 좌표와 이미지 패킹 검사를 통과했다. 최종 기본 메시 삼각형 수는 107,621개이며 렌더용 subdivision 적용 후 수치는 더 많다.

### 범위와 남은 과제

이번 결과는 Blender에서 검토하는 개선 작업본이다. 얼굴은 기존 루나의 형태·눈 텍스처를 유지하면서 표면을 부드럽게 했다. 원화 얼굴을 그대로 재조형하거나 표정 세트를 새로 만든 작업은 아니다. 원화의 아주 가는 잔머리는 추가 조형 여지가 있다.

첫 개선 단계에서는 애니메이션·FBX·모바일 최적화를 다루지 않았으며, 아래 후속 단계에서 수행했다. 앱의 기존 `assets/celestial-oracle/` 에셋은 교체하지 않았다. Tripo API를 통한 생성·자동 리토폴로지는 실행하지 않았고, 공식 제작 흐름을 참고해 Blender에서 수정했다.

## Prayers용 최적화와 검사

실제 루나 임포터가 있는 연결 프로젝트는 `/Users/namaste/git/saju_fullstack/saju_world_unity_hall`이며 Unity 버전은 6000.0.56f1이다. 해당 프로젝트를 읽어 `LunaImporter.cs`의 모델 이름·재질 이름·본 재바인딩 방식을 확인했다. 이 작업실에서 출력 패키지를 만들었으며 연결 Unity 프로젝트의 파일과 씬은 변경하지 않았다.

- 176개 본의 이름·계층·rest matrix와 기존 얼굴·입·눈썹 메시를 유지.
- 주요 메시를 합쳐 활성 SkinnedMeshRenderer 8개, 활성 재질 슬롯 12개로 구성. 이 수치는 실제 GPU draw call 측정값이 아니다.
- 머리와 불투명 의상을 아틀라스로 합치고, 사용하는 이미지 6개를 최대 1024px로 제한. 머리에는 알파 블렌딩을 사용하지 않음.
- 근접 대화용 LOD0와 원거리 대안 LOD1 FBX 출력. LOD1은 아직 Unity LODGroup에 연결하지 않음.
- 앉는 자세에서 남색 패널과 흰 안치마가 서로 관통하던 문제를 확인. 게임용에서는 하나의 불투명 치마 표면에 남색·아이보리 패턴을 넣어 중복 표면을 제거.
- 실제 출력 FBX 두 개를 다시 불러와 본·가중치·이미지 경로를 검사. f_char_003의 기존 18개 클립에서 각각 20%·50%·80% 프레임을 평가하고 대표 4개 자세를 렌더.

최종 수치는 `output/mobile/metrics.json`, 파일 해시와 검사 결과는 `output/mobile/verification.json`을 기준으로 한다. 애니메이션 검사는 54개 샘플 프레임의 유한 좌표·범위 검사와 대표 렌더 확인이다. 모든 프레임의 천·머리 충돌 검사나 물리 시뮬레이션, Unity 실행 및 모바일 기기 프로파일링을 수행한 것은 아니다.

머리 v2 최종 결과: LOD0 활성 삼각형 43,729개, LOD1 23,758개. 숨긴 랜턴까지 포함한 전체 메시 기준 편집본 대비 55.9% 감소. 앞머리는 근접 형태를 보존하기 위해 감량하지 않았다. 18개 클립 × 3프레임 검사와 파일 해시 재확인을 통과했고, 실제 게임용 `.blend`의 확대 렌더도 `previews/mobile/hair_*.png`에 저장했다. Blender 새 창에서 `continuous crown hair v2` 파일을 명시적으로 다시 열어 후면 확대 상태로 표시했다.

Unity 반영 시 기존 `LunaImporter.BuildAll`은 열차 NPC와 상담실도 다시 구성하므로 그대로 실행하지 않는다. 모델·텍스처 교체 후 기존 프리팹의 본 이름으로 재바인딩하고, 아틀라스로 바뀐 머리 재질에서 예전 UV용 노멀/마스크 맵을 제거해야 한다. 얼굴 공유 재질은 기존 캐릭터에 영향을 주므로 별도 검토한다.
