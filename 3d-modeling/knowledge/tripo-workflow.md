# Tripo에서 참고한 모델 제작 흐름

확인일: 2026-10-19. 이번 루나는 기존 FBX 기반 모델을 Blender에서 수정했다. Tripo 생성 API를 실행한 결과물이 아니다.

## 공식 문서에서 확인한 내용

Tripo Studio의 Build & Refine는 기본 메시에서 시작해 부위를 나눠 수정한 뒤 텍스처를 적용하는 흐름이다. Segmentation, Retopology, Texture, Rigging 단계를 제공하고 FBX/GLB로 내보낼 수 있다. [공식 Studio 튜토리얼](https://www.tripo3d.ai/blog/tripo-studio-tutorial-english)

H3 멀티뷰 API는 입력 슬롯을 `front, left, back, right` 순서로 받는다. 정면은 필수이며 최소 두 장이 필요하다. 입력 한 장은 image-to-model로 처리한다. 모델·텍스처 seed를 별도로 기록할 수 있다. `generate_parts`는 `texture=true`, `pbr=true`, `quad=true`와 함께 사용할 수 없으므로 실제 호출 전 버전별 제약을 확인한다. [공식 Multiview API](https://docs.tripo3d.ai/model-generation/multiview-to-model-v3-0-v3-1.html)

선명한 윤곽, 단순한 배경, 일관된 조명의 참고 이미지와 Blender에서의 후속 수정을 권장한다. 마케팅 페이지의 속도·개선율·자동 리깅 품질 주장은 이번 작업에서 검증하지 않았다. [공식 입력 이미지 가이드](https://www.tripo3d.ai/tutorials/tripo-ai-image-to-3d-tips)

## 루나에 적용하는 작업 방식 — 프로젝트 판단

1. 원본 콘셉트 시트를 보존하고 정면·측면·후면을 서로 대조한다. 향후 Tripo 입력을 만들 경우 여러 인물과 글씨가 있는 전체 시트를 그대로 업로드하지 말고, 뷰별 단일 전신 이미지로 준비한다. 보이지 않는 반대쪽을 단순 미러링하면 비대칭 슬릿·장식이 뒤집힐 수 있다.
2. 실루엣부터 조정한다. 얼굴·앞머리 → 뒤쪽 긴 머리 → 양쪽 리본 → 드레스 → 작은 장식 순서로 확인한다.
3. 몸, 머리, 리본, 천, 금속을 분리해 편집한다. 큰 머리 실루엣은 입체 메시로 만들고 끝부분의 가는 머리카락만 얇게 표현한다.
4. 형상이 안정되면 천·머리의 거칠기와 금속 반사를 조정한다. 지나친 머리 광택이나 밝은 역광이 형태 오류를 가리지 않도록 한다.
5. 기존 176개 본의 이름·계층·rest matrix를 유지한다. 새 머리카락은 머리에서 몸통으로 가중치를 이어 붙이고 리본 장식은 머리에 연결한다.
6. 정면·측면·후면·얼굴을 같은 조명으로 렌더한다. 정지 렌더 통과와 실제 애니메이션 호환성 검증은 별도 기록한다.

## 축적 규칙

- 실행한 도구·버전, 입력 파일, 재현 명령과 출력 경로를 기록한다.
- 실패한 접근의 원인과 대안을 남긴다. 보이지 않는 문제를 해결됐다고 기록하지 않는다.
- 얼굴 동일성, 어깨/머리 관통, 투명 천 겹침, 손·소품 위치를 렌더에서 확인한다.
- Blender 작업본과 모바일 런타임용 최적화·재질 베이크 결과를 구분한다.
