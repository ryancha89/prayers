# 치즈 — 자유 대화 공통 동작 참고표

**3D 애니메이션 제작 초안 · 1장 소파 대화 기준**

## 사용자 시점과 외형 기준

- **카메라 = 사용자 = 주인공.** 자유 대화에서는 별도 여성 인물의 위치를 따라 옆을 보지 않는다. 듣기와 말하기의 기본 시선은 렌즈, 곧 사용자다.
- C04에서만 잠깐 시선을 벗어났다가 사용자에게 돌아온다. C08의 느린 눈 깜빡임도 사용자를 향한 상태에서 표현한다. 눈맞춤은 자연스럽게 유지하며, 눈을 한 번도 떼지 않는 고정 응시는 피한다.
- **몸 비율은 첨부 참고서의 삼면도를 기준으로 한다.** 넓고 묵직한 몸통과 가슴, 자연스러운 다리 길이, 굵은 꼬리를 유지한다. 공통 동작 그림의 짧고 작은 몸통을 그대로 모델링하지 않는다.
- **동작 그림은 시선·표정·움직임 참고용이다.** 얼굴·무늬는 기존 승인 그림과 참고서에 맞추며, 미간에 새 장식 무늬나 주름을 추가하지 않는다. 삼면도의 뒷면 무늬는 기존 참고서에 적힌 대로 검토가 필요한 초안이다.
- 이 사용자 시점 기준은 기존 참고서의 ‘안긴 장면에서는 카메라가 아닌 사용자 얼굴을 바라본다’는 설명보다 우선한다. 3D에서도 사용자 얼굴과 시점의 목표를 일치시키고, 접촉 동작에 맞춰 시선을 조정한다.

## 기본 원칙

치즈는 태연하고 자존심이 강하며, 능청스러운 유머가 있는 고양이다. 사용자의 비위를 맞추거나 매번 과장되게 반응하지 않는다. 관심과 다정함은 작은 시선·귀·꼬리 움직임으로 드러낸다.

자유 대화 중에는 현재 장소와 자세를 유지한다. 아래 동작은 대화에 덧붙이는 짧은 반응이며, 이동이나 접촉을 자동으로 시작하는 신호가 아니다.

## 동작 연결 기준

**편히 기다리기 → 듣기 → 답변 준비 → 말하기 → 편히 기다리기**

- 짧은 답변은 기본 말하기만으로 충분하다.
- 개성 반응은 필요한 대목에 하나씩 사용한다. 모든 답변에 넣지 않는다.
- 말하기와 듣기를 전환할 때 자세가 튀거나 몸이 순간 이동하지 않도록 연결한다.
- 꼬리·귀·눈 움직임이 한꺼번에 크게 발생하지 않도록 한다.
- 답변 생성이 늦어져도 생각하는 동작을 처음부터 계속 재생하지 않는다.
- 사용자가 한동안 입력하지 않아도 재촉하는 표정이나 동작을 하지 않는다.

## 장소·자세 유지 기준

같은 반응이라도 현재 자세 안에서 표현해야 한다.

| 현재 상태 | 유지할 것 |
| --- | --- |
| 소파에 앉아 있음 | 대화 중 계속 앉은 자리 유지 |
| 소파나 창가 방석에 누워 있음 | 누운 자세에서 눈·귀·고개로 반응. 말하려고 매번 일어나지 않음 |
| 문밖에서 기다림 | 문밖 위치 유지. 명확한 재초대 전에는 실내로 들어오지 않음 |
| 무릎이나 품에 있음 | 선택한 접촉 상태 유지. 갑자기 소파 자세로 바뀌지 않음 |
| 사용자 옆에 따로 앉음 | 거리 유지. 임의로 무릎에 올라가거나 몸을 비비지 않음 |

## 공통 동작과 분리해야 하는 장면 동작

다음 동작은 대화 분위기만으로 자동 실행하지 않는다. 정해진 스토리 진행이나 사용자의 명확한 선택에 연결한다.

- 현관 입장·퇴장·재입장
- 소파나 창가 자리로 이동하기
- 소파에서 내려오거나 올라가기
- 쓰다듬기를 멈춘 손목 위에 앞발 올리기
- 스트레칭 시범
- 무릎에 올라가기·품에 안기기
- 이마를 맞대는 인사
- 눕거나 잠드는 장면 전환

## 제작 우선순위

**우선 제작:** C01~C04 기본 대화 동작 + C05 능청스러운 자신감 + C08 조용히 받아주기

**이후 추가:** 나머지 짧은 반응과 보조 동작

먼저 소파에 앉은 상태로 동작과 연결을 확인한 뒤, 누운 자세·문밖 대기·무릎 위 상태에 적용한다. 표정과 귀·꼬리 움직임은 재사용할 수 있지만, 자세가 달라지면 별도의 조정이 필요하다.
